スライド① Looker Studio概要 のまとめ

内容:①Looker Studioとは ②できること ③GA4とサーチコンソールの連携 ④連携後のレポート作成

1. Looker Studioとは

  • GA4やサーチコンソールなどのデータを、読みやすく共有しやすい形で柔軟にカスタマイズできる無料のツール
  • GA4とサーチコンソールのデータを1つのレポートにまとめられるので、クライアントへの提出資料に便利
  • PDFでダウンロードできるので、紙やファイルでの共有もできる

2. できること

  • 複数のデータを1つのレポートで見せられる(GA4とサーチコンソールを同じレポートに)
  • グラフや表でデータを可視化できる。GA4のいろいろなデータ項目を1画面で数字とグラフにできる。サーチコンソールはキーワード一覧を作れる
  • レポートの例
    • スコアカード:オーガニック検索・セッション・ユーザー・新規ユーザー・ページビュー数(前期比の増減つき)
    • 流入経路の円グラフ(Organic Search、Paid Search、Direct、Display、Social、Referral、Email など)
    • ページビュー数とオーガニック検索数の月別の折れ線グラフ(前年と比較)
    • ページタイトル別の表(検索数、PV数、閲覧開始数、平均ページ滞在時間、直帰率など、前期比つき)
    • 検索キーワード別の表(クリック数、表示回数、平均掲載順位、クリック率、前期比つき)

3. GA4とサーチコンソールの連携

3-1. ログイン

  • Googleで「データポータル」と検索するとLooker Studioが出てくる → Google Cloudに移動 →「Looker Studioを使ってみる」→ 使うGoogleアカウントでログイン

3-2. GA4を連携

  1. 「空のレポート」を選び、アカウントの設定(国・会社名など)を完了させる。個人で使う場合、会社名は「○○○」などでよい
  2. 「データのレポートへの追加」で「Googleアナリティクス」を選ぶ
  3. 承認画面で「承認」→ ログインしたGoogleアカウントで閲覧権限のあるサイトが選べる
  4. 「アカウント」→「プロパティ」を選び、「追加」をクリックで連携完了
  • 連携するとできること:ユーザー属性(男女比・年齢など)の円グラフ、流入経路、セッション数やPV数のスコア、ページごとのPV数や直帰率の一覧 など
  • データが共有されている場合は「共有アイテム」から見られる

3-3. サーチコンソールを連携

  1. 「データを追加」→「データのレポートへの追加」→ データソース一覧から「Search Console」を選び、Googleアカウントを選択
  2. 「承認」→ 閲覧権限のあるサイトを選ぶ
  3. 「表」で「サイトのインプレッション」か「URLのインプレッション」を選ぶ
  4. 「プロパティ パラメータ」は選ばなくても追加できるので、右下の「追加」をクリック
  • 連携するとできること:キーワード一覧の表の作成

「サイトのインプレッション」と「URLのインプレッション」の違い

  • サイト単位で集計するか、URL単位で集計するかの違い
  • 例:「Shareway セミナー」の検索結果に、自社の5ページ(1位 セミナーページ、2位 セミナーレポート、3位 TOPページ、4位 カピマルweb、5位 商品サービス)が出た場合
指標 サイト別集計 URL別集計
表示回数 1回 5回
クリック数 1回(1位をクリック後、戻って2位をクリックしても1回) 1回以上(同じ操作なら2回)
平均掲載順位 1位 3位((1+2+3+4+5)÷5)
  • サイト別集計:一番順位の高いページのデータだけを集計する
  • URL別集計:表示されたページすべてのデータを集計する
  • 集計方法が違うので、使えるディメンションや指標も違う
    • サイト:ディメンション(Country、Date、Device Category、Google Property、Query)/指標(Average Position、Clicks、Impressions、Site CTR)
    • URL:ディメンションに「Landing Page」が加わる/指標(Impressions、Url Clicks、URL CTR)
  • **SEOのレポートなら「サイトのインプレッション」**を選ぶ。1つのキーワードで表示させたいページは1つのはずなので、複数URLのデータを集計する必要はあまりない。ただし、作りたいレポートによってはURLのインプレッションを選んでもよい

4. 連携後のレポート作成

  • 「グラフを追加」でグラフの種類を選ぶ。紹介されているのは「表」「スコアカード」「期間(時系列)」「円」の4つ
  • グラフごとに「データソース」「ディメンション」「指標」を設定すると、見せたいデータのグラフになる
項目 説明
データソース 使うデータを選ぶ
ディメンション 表やグラフの軸になるデータ(例:キャンペーン、広告、クエリ)
指標 ディメンションに関連する数値(例:クリック数、表示回数)
並べ替え 特定の指標を基準に並べ替える
サブの並べ替え 並べ替えの次に優先する基準
日付範囲 データの取得範囲。カスタムで任意の日付を選べる
フィルタ 特定のキーワードを含むものだけ表示するなど。条件は自分で作る
  • 手順:「編集」をクリック → 見たいデータのグラフ形式を選ぶ
  • 複数人で使うときは、データを上書きしないようにページを分けて運用する

スライド② リスティング広告データ確認方法 のまとめ

Google広告のデータをLooker Studioで確認・レポート化する手順

連携

  1. 「使ってみる」→「空のレポート」→「Google広告」を選ぶ
  2. 該当の広告アカウントを選び、「追加」で連携完了

レポートの作り方(テンプレートを使う前提)

  • テンプレートには「1.全体サマリー」として「キャンペーン別サマリー」と「期間別サマリー」の表がある
  • パワーポイントと同じように「テキスト」が入っているので、施策名と媒体名はテキストに書く(背面に月別の表があるので注意)
  • 表には、先ほど連携したデータソースを選ぶ
  • 「ディメンションを追加」で表の一番左の列(軸)を設定する。表にはExcelのように自由にテキストを書くことはできない
  • 指標は普段のレポートと同じ仕様(表示回数、クリック数、クリック率、平均クリック単価、費用、コンバージョン、コンバージョン率、コンバージョン単価など)。追加したいときは「指標を追加」
  • 2つのブロックは同期しているので、期間を変えたいときは1つ目のブロックで変える
  • 集計表は「合計」が表示されているか確認する
  • 並べ替え:月の横のアイコンから基準(月別なら「月」)を選び、昇順か降順を選ぶ
  • 「キャンペーン別サマリー」と「期間別サマリー」は期間設定が別。期間別で1年分を出したいときは「カスタム → 今月 → 今年」にする
  • 日別にしたいときは、ディメンション(表の軸)を「日」にする

キャンペーンごとのシート

  • フィルタを使う:「フィルタ → フィルタを追加 → フィルタの作成」
  • フィルタ名を付け、「一致条件 → キャンペーン → 含む → キャンペーン名(例:弁当箱訴求)」で保存し、そのフィルタを選ぶ

検索キーワードのシート

  • ディメンションに「検索キーワード」と「マッチタイプ」を入れる
  • マッチタイプは英語で表示されるので注意:部分一致=Broad、完全一致=Exact、フレーズ一致=Phrase
  • 1ページあたりの行数を5000にしておくと、表示モードでページを切り替えずに確認できて便利

内容:Looker Studioとは/できること/基本操作/計算フィールド

Looker Studioでできること

  • 細かく設定できるグラフや表でデータを可視化する
  • いろいろなデータソースに簡単に接続する
  • インサイトをチームと共有・公開する、レポートで共同作業する
  • 組み込みのサンプルレポートで素早くレポートを作る

データの可視化

  • 線グラフ、棒グラフ、円グラフ、地図、面グラフ、バブルチャート、ページ割りされた表、ピボットテーブルなど
  • 閲覧者フィルタや期間設定でレポートをインタラクティブにできる。誰でも自分のデータ確認に使える柔軟なテンプレートを作れる
  • リンクやクリックできる画像を入れて、商品カタログや動画ライブラリなどを作れる
  • テキストや画像でアノテーション・ブランディングができる。スタイルやカラーテーマで見せ方を調整できる

接続できるデータ

  • データベース(BigQuery、MySQL、PostgreSQL など)
  • Googleマーケティングプラットフォーム(Google広告、アナリティクス、ディスプレイ&ビデオ360、検索広告360 など)
  • Googleの一般向けサービス(スプレッドシート、YouTube、Search Console など)
  • CSVファイルのアップロード、Google Cloud Storage経由のファイル
  • ソーシャルメディア(Facebook、Reddit、Twitter など)
  • 複数のソースを組み合わせた混合データ
  • データを追加する画面にはいろいろなテンプレート(コネクタ)があるが、非公式なものも多い

基本操作:Google広告のデイリーレポート(自動更新)を作る

  • クライアントから多い「デイリーで数値を報告してほしい」という要望に対応する
  1. 該当のGoogle広告アカウントを選んで「追加」で連携
  2. 「表」を選び、指標とディメンションを要望どおりに変える
  3. 「コントロールを追加」から期間設定を置くと、期間を自由に切り替えられる(期間をコントロールしたい表の近くに置く)
  4. 「ディメンションを追加」で表の一番左の列を設定する(表にはExcelのように自由にテキストを書けない)
  • 以降の操作(合計の確認、並べ替え、キャンペーン別・期間別サマリーの期間設定、フィルタでキャンペーンごとのシート、検索キーワードとマッチタイプ、1ページの行数5000)は、上の「スライド② リスティング広告データ確認方法」と同じ
  • 「挿入」から、いろいろなグラフ・リスト・画像などを追加できる
  • ページを増やして複数のレポートを作れば、週次・月次のレポートも自動作成できる

計算フィールド

  • クリック単価や費用などを**グロス表記(マージン込み)**にしたい場合は、データパネルの下にある「計算フィールドを追加」を使う
  • 「フィールド名」と「計算式」を入れる。関数を使って、意図した数値を表示できる
    • 例:マージン20%の場合、フィールド名「費用(G)」、計算式 ROUND(費用 / 0.8, 0)
  • グロス表記にした指標は、表に「(G)」と付けて組み込む
