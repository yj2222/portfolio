1. X広告とは(3〜12ページ)

Xの利用者(X社メディア資料より)

  • 日本の収益化できる月間アクティブユーザー(mMAU):6,700万(2023年平均)
  • 日本の収益化できる1日あたりアクティブユーザー(mDAU):4,000万(2022年5月)
  • 日本のXユーザーの平均年齢:37歳
  • Xで情報検索をしたことがある人は87%。そのうち75%が「Xは新しいことが発見できる場所」と回答(ディスカバリー・マインドセット)
  • 企業などの公式アカウントの投稿を見ている人が他SNSより37%多い
  • 3人に2人が「Xには共感できる話題がある」と回答(話題にしてくれる)

キャンペーン目的・課金・入札

# 目的 課金 入札 最適化
1 リーチ CPM(インプレッション課金) 自動入札、目標コスト 最大リーチ(推奨)/エンゲージメントを伴うリーチ
2 動画の再生数 CPV 自動入札、上限入札単価 15秒/2秒50%表示、3秒100%表示、6秒50%表示の再生数
3 フリーロール再生数 CPV 自動入札、上限入札単価 同上(フリーロール)
4 アプリのインストール数 CPAC 自動入札、目標コスト インストール数/アプリのクリック数/アプリ内購入(Androidのみ)
5 アプリのリエンゲージメント数 CPAC 自動入札、目標コスト アプリのクリック数
6 サイト内のクリック数 CPM 自動入札、目標コスト サイト訪問/リンクのクリック数
7 売上(旧コンバージョン) CPM 自動入札、目標コスト ウェブコンバージョン
8 キーワード CPLC 自動入札、上限入札単価 リンクのクリック/サイト訪問/ウェブCV/アプリのインストール

目的の使い分け

  • リーチ:認知を広げたいとき。クリックより「見てもらうこと」が目的(新しいスクールやイベントの告知など)
  • 動画の再生数:動画をできるだけ多く再生してもらいたいとき。ブランドストーリーや体験紹介向け
  • フリーロール再生数:6秒以内の短い動画をスキップされずに見せたいとき。ロゴやキャッチコピーで認知を上げたいとき
  • アプリのインストール数:アプリの新規ユーザーを増やしたいとき(ゲーム、ECアプリなど)
  • アプリのリエンゲージメント数:すでにアプリを入れている人に、もう一度使ってもらいたいとき
  • サイト内のクリック数:サイトやLPへのアクセスを増やしたいとき(商品ページ、資料請求ページへの誘導)
  • 売上:資料請求・会員登録・購入などの成果を増やしたいとき。計測タグのデータで最適化される
  • キーワード:「副業」「転職」「料理」など、特定の話題に関心がある人に出したいとき。まだ自社を知らないが関心はありそうな層に有効

ターゲティング

  • 複数のメッセージをテストすることと、届けたい人を見定めてターゲティングすることが成功のカギ
  • 獲得に貢献できるターゲティング手法
手法 内容
フォロワーと類似ユーザー 特定アカウントのフォロワーと、それに似たユーザーに届ける
興味関心 300以上のカテゴリーから選ぶ
キーワード・絵文字 ポストや検索のキーワード(絵文字も可)で届ける
カスタムオーディエンス サイト訪問者、メールアドレス、モバイルIDで特定のユーザーに届ける
サブスクライバー Xプレミアムの加入者に届ける
会話トピック ユーザーが関心のある会話トピックをリストから選ぶ
エンゲージャー 特定のポストに反応したユーザーに再配信する
最適化ターゲティング 成果が上がりそうなら、指定外のユーザーにも配信する
ブランドセーフティ管理 特定のキーワード・ハンドル名・ポストの近くに出さないようにする
  • 掛け合わせられるターゲティング:地域(国・エリア・都道府県・半径)、言語(20か国語)、性別、携帯キャリア、端末(新端末・iOS/Android・PCなど)

掲載イメージ・参考値(11ページ)

  • プロモポスト:タイムラインに広告主のポストを差し込む。「外部誘導」と「情報拡散」が目的
  • 特定のキーワードをポストした人、特定アカウントのフォロワーなどに絞れるので、特定の物事に興味がある人への訴求に向いている
  • 参考値(予算50万円の場合):クリック単価 約50〜120円、クリック数 約4,000〜10,000回
  • 国内ユーザー数 4,500万人、年齢層は10代〜40代

アカウント構造(12ページ)

  • キャンペーン:目的(コンバージョン、エンゲージメント、フォロワーなど)、日予算、スケジュール
  • 広告グループ:ターゲット(性別、年齢、興味関心、フォロワー、キーワードなど)
  • 広告:配信するクリエイティブ

2. 入稿方法(14〜33ページ)

  1. Xにログインし「もっと見る」→「広告」→ 国で「Japan」を選び「最初の広告を作成」
  2. キャンペーンの目的とキャンペーン名を設定する
  3. 日予算を設定する。推定オーディエンス数(配信される想定人数)が表示される
    • 多い場合:広く届いて認知が上がる、多様な反応データが集まる
    • 少ない場合:狙った人に絞れて効果が上がりやすい、無駄な配信が減る
  4. コンバージョンイベントを「新規作成」する
    • イベント名と種類を設定 →「コードを使ってイベントを定義」を選ぶ
    • イベントID と XピクセルID をメモしておく
  5. ターゲット属性を選び、目標CPAを設定する
  6. GTMでタグを入れる
    • ベースピクセル:タグテンプレート「Twitter Base Pixel」を追加し、XピクセルIDを入れる。トリガーは「All Pages – ページビュー」
    • CVタグ:タグテンプレート「Twitter Event Pixel」を追加し、イベントIDを入れる。トリガーはサンクスページの表示など、CVにあたるもの
    • ベースには「ピクセルID」、イベントには「イベントID」。取り違えに注意
  7. Xの配信設定画面に戻り、ページを更新すると追加したアクションが表示される
  8. クリエイティブを作る。新しく広告用に作るか、通常のポストをそのまま広告に使える
  9. 問題がなければ「キャンペーンを開始」

3. 目的別の分析・改善ポイント(34〜41ページ)

目的 見る指標 改善ポイント
リーチ インプレッション、リーチ、頻度、エンゲージメント率 頻度が5回以上ならクリエイティブ疲れ → 差し替え。反応が低ければ見出しのフックや画像を改善。リーチ単価が上がるなら地域・年齢・興味関心を少し絞る
動画の再生数 再生数(3・6・15秒)、再生率、完了率、再生単価 再生率が低い → 冒頭3秒に結論やキャッチコピー。完了率が低い → 10〜15秒に短縮。単価が高い → ターゲットが狭すぎ・入札が高すぎ
フリーロール 6秒視聴率、スキップ率、広告想起率 テンポ・BGM・フォントなど瞬間的なインパクトを強化。ブランド名・訴求を1秒目に出す。ロゴ中心/メッセージ中心でA/Bテスト
アプリインストール CTR、インストール数・率、CPI CTRが低い → 「無料体験」など具体的なベネフィット。インストール率が低い → ストアページ改善。CPIが高い → 類似オーディエンスへ広げる
アプリのリエンゲージメント CTR、起動数、再利用率、CPC 「期間限定特典」など戻ってくる理由を強調。起動率が低い → ディープリンクの設定ミスを確認。「30日以上未起動」などで分ける
サイト内のクリック CTR、CPC、滞在時間・直帰率(GA4)、LPの表示速度 見出しを質問形式に(「あなたのCVR、落ちてませんか?」)。CPCが高い → 関連の薄い配信面を除外。滞在が短い → LPと広告の内容を合わせる
売上 CV数、CVR、CPA、CTR CVRが低い → LPのCTA配置・フォームの長さ・実績や口コミ。CPAが高い → ターゲットとLPのずれ。CTRが低い → ベネフィット・価格・証拠の訴求を強化
キーワード CTR、キーワード別のCVR・CPA キーワードと広告文を一致させる(「副業」→「副業に使えるマーケスキルとは?」)。成果の高いキーワードに予算を寄せ、低いものは除外。ネガティブキーワードを設定

4. X広告で重視すべき数値(42〜44ページ)

  1. 最重要はエンゲージメント率
    • Xは「反応される投稿」を優先して表示する。CTRより、いいね・リポスト・返信・プロフィールクリックなどの総合的な反応率が効果に直結する
    • 反応が高いほど配信コストが下がる。反応が薄いとCPMが上がり、配信が急に減る
    • CVRより先に、まずエンゲージメント率で勝つことが第一段階
  2. 次にCTRとLP体験
    • Xはスクロールが速く、クリックの意図が浅い。CTRが高くてもLPで離脱されやすい
    • GA4で広告経由の滞在時間・スクロール率を見る。広告文とLPのメッセージが一致しているか確認する
  3. 最終的には間接効果も含めてCVを評価する
    • Xは「広告 → 検索 → 後日CV」が多い。GA4で指名キーワード経由のCVが増えているかを見る
    • 例:ある教育系スクールでは、X広告の直接CVは少なかったが、配信期間中に指名検索からのCVが1.7倍になった

5. PDCAの回し方(45ページ)

  • 1週目:初期仮説
    • 目的を「認知・興味・行動」のどれに置くか決める
    • 訴求軸を3種類ほどに分けてテストする(例:機能訴求「最短3カ月で転職可能」/共感訴求「未経験でも安心」/実績訴求「卒業生の満足度92%」)
  • 2週目:初期データ分析
    • エンゲージメント率は0.5%以上なら投稿の質は良好
    • CTRは平均0.8〜1.5%で、1%を超えれば合格点
    • コメントのポジティブ・ネガティブ両方を見て、次のクリエイティブに活かす
  • 3週目:方向性の判断
    • 反応の良い投稿を残し、ほかは止める
    • 効果の高い訴求軸を1〜2個に絞って、画像・文面のバリエーションを作る
    • 「反応 → クリック → LP滞在 → CV」の順に改善する
  • 4週目以降:中長期の改善
    • Xピクセルで「Web訪問者」「動画再生者」などをリターゲティングする
    • 共感した層をもとに類似オーディエンスを広げる
    • GA4で直接CV以外の指名流入も追う
  • ポイント:Xでは「コメント欄=一次調査データ」。反応をそのままコピーの改善に使うと、CTRを早く底上げできる

6. Facebook広告・LINE公式アカウントとの違い(46ページ)

比較項目 X広告 Facebook広告 LINE公式アカウント
配信ロジック 拡散・共感型(投稿性重視) 精緻なAI最適化(CV学習重視) リーチ+メッセージ型(既存の接点重視)
主な成功要因 反応率・話題性 データ学習量・ターゲティング精度 接触頻度と友だちリストの運用
コンテンツ 投稿・会話・共感 ビジュアル訴求(静止画・動画) クーポン・案内などの情報配信
PDCAの軸 「何が話題化するか」 「誰に当てるか」 「いつ届けるか」

スライド② X広告アカウント作成 のまとめ

  1. https://x.com に、広告を配信するアカウントでログインする
    • X広告アカウントを作るには、XアカウントがXの規則とポリシーに従っている必要がある
  2. 「もっと見る」→「広告」をクリック
  3. 国とタイムゾーンを選ぶ(日本で配信するなら Japan Time のままでよい)。アカウント作成後は変更できない
  4. 「最初の広告を作成」をクリック
  5. 支払い情報(カード)を入力して保存する
