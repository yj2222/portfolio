スライド Yahoo!広告_01 のまとめ

この授業で覚えること:Yahoo!広告の概要/入稿方法(リスティング広告・ディスプレイ広告)

1. Yahoo!広告の概要(3〜11ページ)

広告の種類

  • Yahoo!リスティング広告(検索広告):検索キーワードに連動して表示される検索連動型広告。Yahoo! JAPANと提携サイト(Ameba・bing・エキサイト・@nifty・So-net)の検索結果に出る
  • Yahoo!ディスプレイ広告(YDA):閲覧中・閲覧していたサイトの内容に関連する広告を出す興味関心連動型広告。Yahoo! JAPANと提携サイトに出る

リスティング広告

  • 検索結果の上部・下部に出るテキスト型の広告
  • 検索したキーワードと設定したキーワードが一致すると表示される(一致しなくても、似ていれば出せる手法もある)
  • マッチタイプ
    • インテントマッチ:登録キーワードの類義語や関連する検索にも表示する。最も多く表示される
    • フレーズ一致:登録キーワードが語順どおりに含まれる検索で表示する。語順が入れ替わったり、間に別の語が入ったりすると対象外
    • 完全一致:登録キーワードと完全に一致、または類似パターンのときだけ表示する

ディスプレイ広告(YDA)

  • 「狙いたいターゲットの属性」「過去にサイトを訪れた人」などの条件に合うユーザーが見ているYahoo! JAPANや提携サイトに表示する
  • ターゲティングの種類
種類 内容 向いている用途
性別 配信する性別を指定 性別で購買傾向が違う商品
年齢 配信する年齢層を指定 特定の年齢層向けの商品
オーディエンスリスト サイト訪問者や特定の行動をした人をリスト化して配信 リターゲティング(購買意欲の高い人に再アプローチ)
サーチキーワード 過去に特定のキーワードで検索した人に配信 検索意図がはっきりした人への配信
プレイスメント 配信するサイト・ページを指定 特定のサイトに出したいとき
地域 都道府県・市区郡単位で指定 地域限定の商品
曜日・時間帯 配信する曜日・時間を指定 活動時間に合わせた配信
デバイス PC・スマホ・タブレット、OSを指定 デバイスごとの行動に合わせた配信
コンテンツキーワード ページやアプリの内容をキーワードで指定 特定のトピックに関心がある人
  • 掲載面の例:Yahoo!ニュースの記事ページ(右カラムや記事下)、スマホ版のYahoo!ニュース、Yahoo! JAPANトップページの右カラム(例:dodaの求人広告)
  • 事例:「Yahoo! JAPAN ブランドパネル」(YDAのメニューの1つ。PC版トップページ右上に出る大型のディスプレイ広告)
    • 入稿できる広告:静止画 600×600px(掲載サイズ350×350)/動画 600×600px(掲載サイズ350×350)/動画 640×360px(掲載サイズ350×197)

広告表示オプション(11ページ)

  • 見出し・説明文・URLに加えて、追加情報を表示する機能。設定しても必ず表示されるわけではない
    • テキスト補足オプション:リンクなしの追加テキスト。見出し・説明文に入りきらない情報を補う
    • カテゴリ補足オプション:商品の特性に合わせたカテゴリーと語句を表示し、競合と差別化する
    • クイックリンクオプション:見出しとは別のURLへのリンクを付ける。目的のページに直接行けるのでCTRが上がりやすい
    • 電話番号オプション:スマホでタップして電話できる。電話の申込・問い合わせを増やしたいときに有効

2. アカウント構造(13〜14ページ)

  • クライアントごとにアカウント(基本は企業名)を作る
  • アカウント > キャンペーン > 広告グループ > キーワード・広告文
  • キャンペーンや広告グループは「訴求内容」や「種類」で分ける。ただし細かく分けすぎると最適化に時間がかかる
  • 分け方の例
    • キャンペーンA:通常の集客用(広告グループ:指名ワード/一般ワード)
    • キャンペーンB:セミナー集客用(広告グループ:指名ワード/セミナーワード)
    • 商材ごとに分ける例:ベッド用キャンペーン、TV台用キャンペーン(それぞれ指名ワード/商材ワード)
    • こう分けておくと、あとで効果検証がしやすい
  • 配信のオン・オフを設定しないと配信は始まらない。オン・オフの強さは キャンペーン > 広告グループ > 広告(キーワード)。広告がオンでも、キャンペーンがオフなら配信されない

3. リスティング広告の入稿(16〜26ページ)

  1. 「キャンペーン作成」→「標準」をクリック
  2. キャンペーン名、1日の予算、(決まっていれば)開始日・終了日を入れる
  3. 入札は、開始当初は手動入札・拡張クリック単価を推奨。必要に応じて曜日・時間帯、デバイス、エリアの入札調整を設定する
  4. 自動入札の種類(目的で選ぶ)
自動入札 目的 内容
クリック数の最大化 サイトアクセスを増やしたい 予算内でクリック数が最大になるよう調整
コンバージョン数の最大化 予算を使い切ってCVを増やしたい 予算内でCV数が最大になるよう調整
拡張クリック単価 CVの件数を増やしたい 手動の入札価格を基準に、CVにつながりそうなクリックで調整
コンバージョン単価の目標値 CPAを一定に保ちながらCVを増やしたい 目標CPAでCVを最大限取るよう調整
広告費用対効果の目標値 CVごとに価値が違い、目標ROASを達成したい 目標ROASを保ちながらCV価値を最大化
  1. 広告の表示対象は、指定がなければ「ウェブサイト検索のみ」を選ぶ(「全て」にすると画像検索なども対象になる)
  2. 配信したくないキーワードがあれば除外を設定する。トラッキングURLを付ける場合はここで設定する
  3. コンバージョンの単位
    • アカウント単位:全キャンペーンに共通のゴール(会員登録、全商品の購入など)がある場合
    • キャンペーン単位:商品やサービスごとにゴールが違い、個別に最適化したい場合
  4. 広告グループ名、デフォルトのクリック単価、(必要なら)デバイスの入札比率を設定する
  5. 広告の配信方法は基本「優先する」。複数の広告を入れたとき、CTR・CVRが高い広告を自動で多く出してくれる
  6. キーワードを入れる。Google広告のように記号を付けるのではなく、プルダウンでマッチタイプを選ぶ
  7. 広告見出しを入れる(表示位置を固定したい見出しはここで固定する)
  8. 説明文と、クリック後のLPのURLを入れて「作成」
  • 入稿URLには必ずパラメーターを付ける。付けないと、すべて yahoo / organic に分類されてしまう

4. コンバージョン設定・リターゲティングタグ(27〜32ページ)

  • 「ツール」→「コンバージョン測定」→「コンバージョン設定を作成」
  • コンバージョン名、コンバージョン種別、計測方法(毎回か1回か)、1件あたりの価値(なければ空欄でよい)を入れる
  • 「タグを表示」でタグを確認する(表示まで時間がかかることがある)。YDAでも同じ手順
  • リターゲティングタグ:「ツール」→「ターゲットリスト」→「タグ・IDを表示」でコピーし、タグマネージャーで設定する

5. ディスプレイ広告(YDA)の入稿(33〜48ページ)

  1. 「キャンペーン作成」→ 目的を選ぶ(獲得案件なら「コンバージョン」)
  2. キャンペーン名、1日の予算、開始日・終了日を入れる
  3. 入札は、最初は「個別クリック単価」で始め、CVが安定したら自動入札に切り替える
  4. 広告グループ名を入れる(自動入札でキャンペーンと違う入札価格にしたい場合は設定)
  5. ターゲティング
    • 時間帯・曜日、デバイス、地域・性別・年齢で絞る
    • オーディエンスリスト
      • 興味関心:商品に興味がある潜在層へ配信。潜在顧客の集客やブランド認知向け
      • 購買意向:検索やカート追加など購買を検討している人、旅行・結婚などを計画している人(顕在層)へ配信
    • サーチキーワードリスト:過去に検索したキーワードをもとに配信する。YDA独自の機能で精度が高い
      • キーワードを入れるかURLを設定すると候補が出るので、振り分けてリストを作る
    • プレイスメントリスト:配信したいサイトをリスト化して指定できる。カテゴリーで指定することもできる
  6. 「レスポンシブ広告を追加」→ 画像か動画を選ぶ → 画像をアップロード → タイトル・説明文・ボタン文言・LPのURLを入れる
  • こちらも入稿URLには必ずパラメーターを付ける(付けないと yahoo / organic になる)
